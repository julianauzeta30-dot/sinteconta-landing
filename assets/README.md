# Recursos visuales versionados

Esta carpeta contiene las copias de respaldo versionadas de todas las imágenes, logotipos y el video que utiliza la landing de Sinteconta.

| Recurso | Uso en la landing |
| --- | --- |
| `sinteconta-hero-background.mp4` | Video de fondo del hero. |
| `sinteconta-hero-reference.jpg` | Imagen de respaldo del hero. |
| `sinteconta-servicios-personas.jpg` | Imagen principal de servicios. |
| `sinteconta-proceso.jpg` | Imagen de la sección Quiénes somos. |
| `sinteconta-equipo.jpg` | Imagen de la sección Equipo. |
| `sinteconta-contacto.jpg` | Imagen de la promoción y contacto. |
| `sinteconta-logo-horizontal*.png` | Versiones clara y oscura del logotipo horizontal. |
| `sinteconta-isologo*.png` | Versiones clara y oscura del isologo. |

La landing publicada continúa cargando los recursos desde rutas `/manus-storage/` para que el despliegue estático no incluya medios pesados. Estas copias dejan el proyecto autónomo como repositorio de código y respaldo de marca. Si se cambia un recurso, actualiza tanto esta carpeta como la ruta de almacenamiento que utiliza la aplicación.
